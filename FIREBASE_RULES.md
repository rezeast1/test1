# Firebase Rules для TopGlass

## Описание правил безопасности

Этот файл содержит правила безопасности для Firebase Realtime Database.

### Структура правил:

#### 1. **users** - Пользователи
- **Чтение**: Все авторизованные пользователи могут читать список пользователей
- **Запись**: Пользователь может изменять только свои данные, либо админ может изменять любые данные

#### 2. **admins** - Список администраторов
- **Чтение**: Все авторизованные пользователи могут проверить, является ли кто-то админом
- **Запись**: Запрещена (управляется вручную через Firebase Console)

#### 3. **articles** - Статьи базы знаний
- **Чтение**: Все авторизованные пользователи
- **Запись**: Только администраторы
- **Исключения**: Все пользователи могут обновлять счётчики `views`, `helpful`, `notHelpful`

#### 4. **suggestions** - Предложения новых тем
- **Чтение**: Только администраторы
- **Запись**: Все авторизованные пользователи могут создавать предложения, только админы могут изменять/удалять

#### 5. **glassSuggestions** - Предложения совместимостей стёкол
- **Чтение**: Только администраторы
- **Запись**: Все авторизованные пользователи могут создавать предложения, только админы могут изменять/удалять

#### 6. **feedback** - Отзывы об улучшении статей
- **Чтение**: Только администраторы
- **Запись**: Все авторизованные пользователи могут создавать отзывы, только админы могут удалять

#### 7. **glassLinks** - Связки совместимых стёкол
- **Чтение**: Все авторизованные пользователи
- **Запись**: Только администраторы

## Как применить правила:

1. Откройте Firebase Console: https://console.firebase.google.com/
2. Выберите ваш проект
3. Перейдите в **Realtime Database** → **Rules**
4. Скопируйте содержимое файла `firebase-rules.json`
5. Вставьте в редактор правил
6. Нажмите **Publish**

## Важно:

- Убедитесь, что в базе данных существует узел `admins` с UID администраторов
- Структура: `admins/[UID]/role: "admin"`
- Первого админа нужно добавить вручную через Firebase Console
