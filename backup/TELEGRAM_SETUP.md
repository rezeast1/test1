# Инструкция по настройке Telegram бота для получения предложений

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например, "Wiki Suggestions Bot")
4. Введите username для бота (должен заканчиваться на "bot", например, "wiki_suggestions_bot")
5. BotFather отправит вам **токен бота** - это длинная строка вида:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz123456789
   ```
6. **ВАЖНО**: Сохраните этот токен, он понадобится для настройки

## Шаг 2: Получение вашего Chat ID

### Вариант А: Через бота @userinfobot

1. Найдите в Telegram бота **@userinfobot**
2. Нажмите "Start" или отправьте любое сообщение
3. Бот отправит вам информацию, включая ваш **Chat ID** (число, например: 123456789)

### Вариант Б: Через бота @getmyid_bot

1. Найдите в Telegram бота **@getmyid_bot**
2. Нажмите "Start"
3. Бот отправит ваш **Chat ID**

### Вариант В: Получение ID группы (если хотите получать в группу)

1. Создайте группу в Telegram
2. Добавьте вашего бота в группу (найдите его по username)
3. Сделайте бота администратором группы
4. Отправьте любое сообщение в группу
5. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
   Замените `<ВАШ_ТОКЕН>` на токен вашего бота
6. Найдите в ответе поле `"chat":{"id":-1001234567890}` - это ID вашей группы (отрицательное число)

## Шаг 3: Настройка конфигурации

1. Откройте файл **`telegram-bot.js`** в вашем проекте
2. Найдите объект `TELEGRAM_CONFIG`:

```javascript
const TELEGRAM_CONFIG = {
    botToken: 'YOUR_BOT_TOKEN',
    chatId: 'YOUR_CHAT_ID'
};
```

3. Замените значения:
   - `botToken` - вставьте токен от BotFather
   - `chatId` - вставьте ваш Chat ID (или ID группы)

**Пример:**

```javascript
const TELEGRAM_CONFIG = {
    botToken: '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz123456789',
    chatId: '123456789'  // или '-1001234567890' для группы
};
```

4. Сохраните файл

## Шаг 4: Тестирование

1. Откройте `index.html` в браузере
2. Нажмите кнопку **"Предложить тему"**
3. Заполните форму:
   - Название темы (обязательно)
   - Ключевые слова (необязательно)
   - Описание темы (обязательно)
   - Email (необязательно)
4. Нажмите **"Отправить предложение"**
5. Проверьте Telegram - вам должно прийти сообщение с предложением!

## Формат сообщения в Telegram

Вы получите красиво оформленное сообщение:

```
🆕 Новое предложение темы

📌 Название: TypeScript

🏷 Ключевые слова: программирование, типизация, JavaScript

📝 Описание:
TypeScript - это типизированный надмножество JavaScript...

📧 Email: user@example.com

🕐 Дата: 30.04.2026, 08:48
```

## Безопасность

### ⚠️ ВАЖНО: Защита токена бота

**НЕ публикуйте файл `telegram-bot.js` с реальным токеном в публичные репозитории (GitHub, GitLab и т.д.)!**

Если вы используете Git:

1. Создайте файл `.gitignore` в корне проекта:
```
telegram-bot.js
```

2. Или создайте отдельный файл конфигурации:
   - Переименуйте `telegram-bot.js` в `telegram-bot.example.js` (без токенов)
   - Создайте `telegram-bot.config.js` с реальными токенами
   - Добавьте `telegram-bot.config.js` в `.gitignore`

### Альтернатива: Использование переменных окружения

Для продакшена рекомендуется использовать серверную часть (backend), которая:
- Хранит токен бота на сервере
- Принимает запросы от фронтенда
- Отправляет сообщения в Telegram от имени сервера

Это предотвращает утечку токена через код на клиенте.

## Дополнительные возможности

### Сохранение предложений в Firebase

Предложения автоматически сохраняются в Firebase Realtime Database (если настроен):

```
suggestions/
  ├─ -N1a2b3c4d5e6f7g8h9i0/
  │   ├─ title: "TypeScript"
  │   ├─ keywords: "программирование, типизация"
  │   ├─ content: "Описание..."
  │   ├─ email: "user@example.com"
  │   ├─ timestamp: 1714456094990
  │   └─ date: "2026-04-30T05:48:14.990Z"
  └─ ...
```

Чтобы просмотреть предложения:
1. Откройте Firebase Console
2. Перейдите в Realtime Database
3. Найдите узел `suggestions`

### Настройка правил Firebase для предложений

Добавьте в правила Firebase:

```json
{
  "rules": {
    "articleViews": {
      ".read": true,
      ".write": true
    },
    "suggestions": {
      ".read": false,
      ".write": true,
      "$suggestionId": {
        ".validate": "newData.hasChildren(['title', 'content', 'timestamp'])"
      }
    }
  }
}
```

Это позволит пользователям отправлять предложения, но не читать чужие.

## Возможные проблемы

### Ошибка: "Telegram бот не настроен"
- Проверьте, что вы заменили `YOUR_BOT_TOKEN` и `YOUR_CHAT_ID` на реальные значения
- Убедитесь, что токен и chat ID скопированы без пробелов

### Ошибка: "Forbidden: bot was blocked by the user"
- Откройте чат с вашим ботом в Telegram
- Нажмите "Start" или отправьте `/start`
- Попробуйте отправить предложение снова

### Ошибка: "Bad Request: chat not found"
- Проверьте правильность Chat ID
- Для групп ID должен быть отрицательным числом (начинаться с минуса)
- Убедитесь, что бот добавлен в группу и является администратором

### Сообщения не приходят
- Откройте консоль браузера (F12) и проверьте наличие ошибок
- Проверьте, что бот не заблокирован
- Убедитесь, что у вас есть интернет-соединение
- Попробуйте отправить тестовое сообщение через API:
  ```
  https://api.telegram.org/bot<ВАШ_ТОКЕН>/sendMessage?chat_id=<ВАШ_CHAT_ID>&text=Test
  ```

### CORS ошибки
Telegram API поддерживает CORS, но если возникают проблемы:
- Убедитесь, что сайт открыт через `http://` или `https://` (не `file://`)
- Для локального тестирования используйте локальный сервер (например, Live Server в VS Code)

## Команды для управления ботом

Полезные команды для @BotFather:

- `/mybots` - список вашихботов
- `/setname` - изменить имя бота
- `/setdescription` - изменить описание
- `/setabouttext` - изменить текст "О боте"
- `/setuserpic` - установить аватар бота
- `/deletebot` - удалить бота

## Лимиты Telegram Bot API

- **30 сообщений в секунду** на всех пользователей
- **1 сообщение в секунду** одному пользователю
- Максимальная длина сообщения: **4096 символов**

Для вики-сайта этих лимитов более чем достаточно!
