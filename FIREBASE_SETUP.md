# Инструкция по настройке Firebase для синхронизации просмотров

## Шаг 1: Создание проекта Firebase

1. Перейдите на [Firebase Console](https://console.firebase.google.com/)
2. Нажмите "Добавить проект" (Add project)
3. Введите название проекта (например, "wiki-views")
4. Следуйте инструкциям (можно отключить Google Analytics, если не нужен)
5. Нажмите "Создать проект"

## Шаг 2: Настройка Realtime Database

1. В левом меню выберите **"Build"** → **"Realtime Database"**
2. Нажмите **"Создать базу данных"** (Create Database)
3. Выберите регион (например, ближайший к вашим пользователям)
4. Выберите режим безопасности:
   - **Для тестирования**: выберите "Start in test mode" (данные доступны всем на 30 дней)
   - **Для продакшена**: выберите "Start in locked mode" (настроим правила позже)
5. Нажмите **"Включить"** (Enable)

## Шаг 3: Настройка правил безопасности

После создания базы данных, перейдите на вкладку **"Rules"** и вставьте следующие правила:

```json
{
  "rules": {
    "articleViews": {
      ".read": true,
      ".write": true,
      "$articleId": {
        ".validate": "newData.isNumber() && newData.val() >= 0"
      }
    }
  }
}
```

Эти правила позволяют:
- Всем читать просмотры (`.read: true`)
- Всем записывать просмотры (`.write: true`)
- Проверяют, что значение - это число >= 0

**Важно**: Для продакшена рекомендуется добавить более строгие правила или аутентификацию.

Нажмите **"Опубликовать"** (Publish)

## Шаг 4: Получение конфигурации Firebase

1. В левом меню нажмите на иконку шестеренки ⚙️ → **"Настройки проекта"** (Project settings)
2. Прокрутите вниз до раздела **"Ваши приложения"** (Your apps)
3. Нажмите на иконку **"</>"** (Web)
4. Введите название приложения (например, "wiki-web")
5. **НЕ** ставьте галочку "Firebase Hosting" (если не планируете использовать)
6. Нажмите **"Зарегистрировать приложение"** (Register app)
7. Скопируйте объект `firebaseConfig`

Он будет выглядеть примерно так:

```javascript
const firebaseConfig = {
  apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX",
  authDomain: "wiki-views-xxxxx.firebaseapp.com",
  databaseURL: "https://wiki-views-xxxxx-default-rtdb.firebaseio.com",
  projectId: "wiki-views-xxxxx",
  storageBucket: "wiki-views-xxxxx.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:xxxxxxxxxxxxx"
};
```

## Шаг 5: Обновление конфигурации в проекте

1. Откройте файл **`firebase-config.js`** в вашем проекте
2. Замените значения в объекте `firebaseConfig` на ваши данные из Firebase Console
3. Сохраните файл

```javascript
const firebaseConfig = {
    apiKey: "ВСТАВЬТЕ_ВАШ_API_KEY",
    authDomain: "ВСТАВЬТЕ_ВАШ_AUTH_DOMAIN",
    databaseURL: "ВСТАВЬТЕ_ВАШ_DATABASE_URL",
    projectId: "ВСТАВЬТЕ_ВАШ_PROJECT_ID",
    storageBucket: "ВСТАВЬТЕ_ВАШ_STORAGE_BUCKET",
    messagingSenderId: "ВСТАВЬТЕ_ВАШ_SENDER_ID",
    appId: "ВСТАВЬТЕ_ВАШ_APP_ID"
};
```

## Шаг 6: Тестирование

1. Откройте `index.html` в браузере
2. Откройте консоль разработчика (F12)
3. Вы должны увидеть сообщение: **"Firebase инициализирован"**
4. Откройте несколько статей - просмотры должны увеличиваться
5. Откройте сайт в другом браузере или в режиме инкогнито - просмотры должны синхронизироваться в реальном времени!

## Шаг 7: Проверка данных в Firebase

1. Вернитесь в Firebase Console
2. Перейдите в **Realtime Database**
3. Вы должны увидеть структуру данных:

```
articleViews
  ├─ 1: 5
  ├─ 2: 3
  ├─ 3: 7
  └─ ...
```

## Возможные проблемы

### Ошибка: "Firebase SDK не загружен"
- Проверьте подключение к интернету
- Убедитесь, что скрипты Firebase загружаются в `index.html`

### Ошибка: "Permission denied"
- Проверьте правила безопасности в Realtime Database
- Убедитесь, что `.read` и `.write` установлены в `true`

### Просмотры не синхронизируются
- Проверьте `databaseURL` в конфигурации
- Откройте консоль браузера и проверьте наличие ошибок
- Убедитесь, что база данных создана в режиме Realtime Database (не Firestore)

## Fallback режим

Если Firebase не настроен или недоступен, сайт автоматически переключится на localStorage (локальное хранилище). В консоли появится сообщение:
```
Используется localStorage (Firebase не настроен)
```

В этом режиме просмотры будут сохраняться только локально в браузере каждого пользователя.

## Безопасность для продакшена

Для публичного сайта рекомендуется:

1. **Ограничить запись**: разрешить только инкремент, запретить произвольные значения
2. **Добавить rate limiting**: ограничить количество запросов с одного IP
3. **Использовать Firebase Authentication**: требовать авторизацию для записи

Пример более безопасных правил:

```json
{
  "rules": {
    "articleViews": {
      ".read": true,
      "$articleId": {
        ".write": "!data.exists() || newData.val() === data.val() + 1",
        ".validate": "newData.isNumber() && newData.val() >= 0"
      }
    }
  }
}
```

Эти правила разрешают только увеличение на 1, что предотвращает накрутку просмотров.

## Стоимость

Firebase Realtime Database имеет бесплатный тариф:
- **1 GB хранилища**
- **10 GB/месяц трафика**
- **100 одновременных подключений**

Для небольшого вики-сайта этого более чем достаточно!
