# DEMO Versions

Этот проект разделён на три демо-версии с разным функционалом:

## 📦 DEMO/lite - Базовая версия
**Для быстрой демонстрации основного функционала**

### Возможности:
- ✅ Поиск по статьям (заголовки, ключевые слова, содержание)
- ✅ Просмотр статей
- ✅ Счётчик просмотров (localStorage)
- ✅ Подсветка найденных слов

### Отсутствует:
- ❌ Firebase интеграция
- ❌ Telegram WebApp
- ❌ Админ-панель
- ❌ Система feedback (лайки/дизлайки)
- ❌ Предложение тем

**Использование:** Открыть `DEMO/lite/index.html` в браузере

---

## 🎯 DEMO/standard - Стандартная версия
**Для демонстрации клиентам с интерактивными функциями**

### Возможности:
- ✅ Всё из lite версии +
- ✅ Telegram WebApp интеграция
- ✅ Система feedback (👍 Полезно / 👎 Не помогло)
- ✅ Предложение новых тем через форму
- ✅ Сбор отзывов пользователей

### Отсутствует:
- ❌ Firebase синхронизация
- ❌ Админ-панель
- ❌ Rich-text редактор
- ❌ Загрузка медиа

**Использование:** Открыть `DEMO/standard/index.html` в браузере или через Telegram WebApp

---

## 🚀 DEMO/pro - Полная версия
**Полнофункциональная версия с админ-панелью**

### Возможности:
- ✅ Всё из standard версии +
- ✅ Firebase Realtime Database
- ✅ Firebase Authentication
- ✅ Админ-панель (добавление/редактирование/удаление статей)
- ✅ Rich-text редактор (Quill)
- ✅ Загрузка изображений и видео
- ✅ Синхронизация данных между устройствами
- ✅ Telegram бот интеграция

**Использование:** 
1. Настроить Firebase (см. `FIREBASE_SETUP.md`)
2. Настроить Telegram бота (см. `TELEGRAM_SETUP.md`)
3. Открыть `DEMO/pro/index.html`

## 🔧 Технологии

- **Lite:** Vanilla JS + CSS
- **Standard:** Vanilla JS + CSS + Telegram WebApp SDK
- **Pro:** Vanilla JS + CSS + Firebase + Telegram WebApp SDK + Quill Editor
