# Обновление Firebase Rules

## Инструкция по обновлению правил безопасности Firebase

1. Откройте Firebase Console: https://console.firebase.google.com/project/topglass-82657/database/topglass-82657-default-rtdb/rules

2. Скопируйте содержимое файла `firebase-rules.json`

3. Вставьте правила в редактор Firebase Console

4. Нажмите кнопку **"Опубликовать"** (Publish)

## Что изменилось

### Добавлены новые разделы:

- **glassLinks** - хранит связки совместимых стёкол
  - Чтение: все авторизованные пользователи
  - Запись: только администраторы

- **glassSuggestions** - хранит предложения пользователей о совместимости стёкол
  - Чтение: только администраторы
  - Запись: все авторизованные пользователи

### Обновлены правила для статей:

- Теперь обычные пользователи могут записывать:
  - `views` - просмотры статей
  - `helpful` - оценки "помогло"
  - `notHelpful` - оценки "не помогло"

- Остальные поля статей (title, content, keywords) могут изменять только администраторы

## Структура данных

### glassLinks
```json
{
  "glassLinks": {
    "linkId1": {
      "phoneModel": "iPhone 12",
      "compatibleModels": ["iPhone 12 Pro", "iPhone 12 Pro Max"],
      "createdAt": 1234567890,
      "createdBy": "admin@example.com"
    }
  }
}
```

### glassSuggestions
```json
{
  "glassSuggestions": {
    "suggestionId1": {
      "phoneModel": "iPhone 13",
      "compatibleGlass": "iPhone 13 Pro",
      "comment": "Проверено на практике",
      "suggestedBy": "user@example.com",
      "suggestedAt": 1234567890,
      "status": "pending"
    }
  }
}
```

## Новые функции

### Главное меню
После авторизации пользователь видит три кнопки:
1. **Тестирование** - раздел в разработке
2. **База знаний** - существующая база знаний
3. **Помощник замены стёкол** - новый раздел

### Помощник замены стёкол

**Для всех пользователей:**
- Поиск совместимых стёкол по модели телефона
- Предложение новых связок совместимости

**Для администраторов:**
- Управление связками стёкол (добавление/удаление)
- Просмотр предложений пользователей

## Тестирование

После обновления правил проверьте:
1. Обычный пользователь может увеличивать просмотры статей
2. Обычный пользователь может искать стёкла
3. Обычный пользователь может предлагать совместимость
4. Администратор может добавлять/удалять связки стёкол
5. Администратор видит кнопку "Управление связками"
