# Инструкция по запуску системы предложений тем

## Как это работает

Теперь предложения тем отправляются через вашего Python бота специалисту (ID: 743066247).

**Схема работы:**
1. Пользователь заполняет форму на сайте
2. Сайт отправляет данные на локальный сервер Python бота (порт 8080)
3. Python бот пересылает сообщение специалисту в Telegram
4. Специалист получает красиво оформленное уведомление

## Запуск системы

### Шаг 1: Установите необходимые библиотеки (если еще не установлены)

Откройте командную строку в папке с ботом и выполните:

```bash
pip install aiogram aiohttp
```

### Шаг 2: Запустите Python бота

```bash
python "import asyncio.py"
```

Вы должны увидеть:
```
Бот запущен и готов к работе...
Веб-сервер запущен на порту 8080
```

**ВАЖНО:** Бот должен быть запущен постоянно, пока работает сайт!

### Шаг 3: Откройте сайт

Откройте `index.html` в браузере (можно просто двойным кликом).

### Шаг 4: Протестируйте

1. Нажмите кнопку **"Предложить тему"**
2. Заполните форму:
   - Название: "Docker"
   - Ключевые слова: "контейнеризация, DevOps"
   - Описание: "Docker - платформа для контейнеризации приложений"
   - Email: test@example.com (необязательно)
3. Нажмите **"Отправить предложение"**
4. Проверьте Telegram - специалисту должно прийти сообщение!

## Возможные проблемы

### Ошибка: "Бот не запущен"

**Причина:** Python бот не запущен или веб-сервер не работает.

**Решение:**
1. Убедитесь, что Python бот запущен (`python "import asyncio.py"`)
2. Проверьте, что в консоли есть сообщение "Веб-сервер запущен на порту 8080"
3. Проверьте, что порт 8080 не занят другим приложением

### Ошибка: "Failed to fetch"

**Причина:** Сайт не может подключиться к боту.

**Решение:**
1. Убедитесь, что бот запущен
2. Проверьте, что в `telegram-bot.js` указан правильный URL: `http://localhost:8080/api/suggest`
3. Откройте сайт через `http://` (не `file://`) - используйте локальный сервер или Live Server в VS Code

### Сообщения не приходят специалисту

**Причина:** Неправильный ID специалиста или бот не запущен.

**Решение:**
1. Проверьте, что в `import asyncio.py` строка 12 содержит правильный ID: `SPECIALIST_ID = 743066247`
2. Убедитесь, что специалист запустил бота (отправил `/start`)
3. Проверьте консоль Python бота на наличие ошибок

### Порт 8080 уже занят

**Решение:**
1. Измените порт в `import asyncio.py` (строка 13):
   ```python
   WEBHOOK_PORT = 8081  # Или любой другой свободный порт
   ```
2. Измените URL в `telegram-bot.js`:
   ```javascript
   const BOT_SERVER_URL = 'http://localhost:8081/api/suggest';
   ```
3. Перезапустите бота

## Запуск на продакшене (публичный сервер)

Если вы хотите разместить сайт на хостинге:

1. **Разместите Python бота на сервере** (VPS, Heroku, Railway и т.д.)
2. **Получите публичный URL** сервера (например, `https://your-bot.herokuapp.com`)
3. **Обновите `telegram-bot.js`:**
   ```javascript
   const BOT_SERVER_URL = 'https://your-bot.herokuapp.com/api/suggest';
   ```
4. **Настройте HTTPS** для безопасности

## Преимущества этого подхода

✅ **Безопасность** - токен бота не виден в коде сайта
✅ **Централизация** - все уведомления идут через одного бота
✅ **Гибкость** - можно легко изменить формат сообщений или добавить логику
✅ **Единый стиль** - сообщения выглядят так же, как "Обратиться к специалисту"

## Дополнительные возможности

### Добавить кнопки в сообщение

Можно добавить кнопки "Одобрить" / "Отклонить" для быстрой обработки предложений.

### Сохранение в базу данных

Предложения уже сохраняются в Firebase (если настроен), но можно также сохранять в SQLite или PostgreSQL на сервере бота.

### Уведомления нескольким специалистам

Можно отправлять уведомления нескольким людям, добавив их ID в список:
```python
SPECIALISTS = [743066247, 123456789, 987654321]

for specialist_id in SPECIALISTS:
    await bot.send_message(chat_id=specialist_id, text=message, parse_mode="HTML")
```
