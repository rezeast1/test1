# Настройка системы авторизации и администратора

## Что было добавлено

1. **Система регистрации и входа пользователей**
   - Форма регистрации с проверкой email и пароля
   - Форма входа для зарегистрированных пользователей
   - Автоматическая проверка авторизации при загрузке сайта
   - **При открытии сайта сразу показывается форма входа/регистрации**

2. **Контроль доступа**
   - Только авторизованные пользователи могут видеть контент
   - Незарегистрированные пользователи видят только форму входа/регистрации

3. **Разделение прав: Администратор и Пользователь**
   - **Администратор** - полный доступ к управлению статьями и пользователями
   - **Пользователь** - только просмотр статей и предложение новых тем

4. **Панель управления пользователями (только для админа)**
   - Просмотр списка всех зарегистрированных пользователей
   - Удаление пользователей из базы данных
   - Защита от удаления администраторов

## Быстрый старт

### Шаг 1: Создайте первого пользователя через Firebase Console

1. Откройте [Firebase Console](https://console.firebase.google.com/)
2. Выберите проект `topglass-82657`
3. Перейдите в **Authentication** → **Users**
4. Нажмите **Add user**
5. Введите:
   - Email: `admin@topglass.com` (или любой другой)
   - Password: `admin123` (или любой другой, минимум 6 символов)
6. Нажмите **Add user**
7. **Скопируйте UID** созданного пользователя (длинная строка типа `xYz123AbC...`)

### Шаг 2: Назначьте пользователя администратором

1. В Firebase Console перейдите в **Realtime Database**
2. Нажмите на корень базы данных
3. Нажмите **+** чтобы добавить новую запись
4. Введите:
   - **Name**: `admins`
   - Нажмите **+** внутри `admins`
   - **Name**: вставьте UID пользователя (из шага 1)
   - Нажмите **+** внутри UID
   - **Name**: `role`
   - **Value**: `admin`
5. Нажмите **Add**

Структура должна выглядеть так:
```
admins/
  └── xYz123AbC.../
        └── role: "admin"
```

### Шаг 3: Войдите на сайт

1. Откройте сайт
2. Вы увидите форму входа
3. Введите email и пароль, которые создали в Firebase
4. Нажмите **Войти**
5. После входа вы увидите кнопки:
   - **Управление пользователями**
   - **Добавить тему**
   - **Сбросить просмотры**

## Создание обычных пользователей

### Вариант 1: Через форму регистрации на сайте (рекомендуется)

1. Откройте сайт
2. Нажмите вкладку **Регистрация**
3. Заполните форму:
   - Имя
   - Email
   - Пароль (минимум 6 символов)
   - Подтверждение пароля
4. Нажмите **Зарегистрироваться**
5. Пользователь автоматически получит роль "user" (обычный пользователь)

### Вариант 2: Через Firebase Console

1. Firebase Console → **Authentication** → **Users**
2. Нажмите **Add user**
3. Введите email и пароль
4. **НЕ добавляйте** пользователя в раздел `admins/` - он автоматически будет обычным пользователем

## Разница между Администратором и Пользователем

### Администратор видит:
- ✅ Все статьи (чтение)
- ✅ Кнопка "Добавить тему" (создание новых статей)
- ✅ Кнопки редактирования и удаления статей
- ✅ Кнопка "Управление пользователями"
- ✅ Кнопка "Сбросить просмотры"
- ✅ Кнопка "Предложить тему"

### Обычный пользователь видит:
- ✅ Все статьи (только чтение)
- ✅ Поиск по статьям
- ✅ Кнопка "Предложить тему"
- ❌ НЕТ доступа к редактированию
- ❌ НЕТ доступа к управлению пользователями
- ❌ НЕТ доступа к сбросу просмотров

## Безопасность

⚠️ **Важно**: Текущая реализация удаляет пользователей только из Realtime Database. Для полного удаления из Firebase Authentication необходимо:

1. Использовать Firebase Admin SDK на сервере
2. Или настроить Cloud Functions для удаления пользователей

### Пример Cloud Function для удаления пользователя:

```javascript
const functions = require('firebase-functions');
const admin = require('firebase-admin');
admin.initializeApp();

exports.deleteUser = functions.https.onCall(async (data, context) => {
    // Проверка прав администратора
    if (!context.auth) {
        throw new functions.https.HttpsError('unauthenticated', 'Требуется авторизация');
    }

    const callerUid = context.auth.uid;
    const isAdmin = await admin.database().ref(`admins/${callerUid}`).once('value');
    
    if (!isAdmin.exists()) {
        throw new functions.https.HttpsError('permission-denied', 'Недостаточно прав');
    }

    const { uid } = data;

    try {
        // Удаляем из Authentication
        await admin.auth().deleteUser(uid);
        
        // Удаляем из Database
        await admin.database().ref(`users/${uid}`).remove();
        
        return { success: true };
    } catch (error) {
        throw new functions.https.HttpsError('internal', error.message);
    }
});
```

## Правила безопасности Firebase

Рекомендуется настроить правила безопасности в Realtime Database:

```json
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "auth != null && (auth.uid === $uid || root.child('admins').child(auth.uid).exists())",
        ".write": "auth != null && auth.uid === $uid"
      }
    },
    "admins": {
      ".read": "auth != null && root.child('admins').child(auth.uid).exists()",
      ".write": false
    },
    "articles": {
      ".read": "auth != null",
      ".write": "auth != null && root.child('admins').child(auth.uid).exists()"
    },
    "suggestions": {
      ".read": "auth != null && root.child('admins').child(auth.uid).exists()",
      ".write": "auth != null"
    }
  }
}
```
