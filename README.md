# TopGlass - База знаний

## 🚀 Быстрый старт

### 1. Создайте администратора в Firebase

1. Откройте [Firebase Console](https://console.firebase.google.com/) → проект `topglass-82657`
2. **Authentication** → **Users** → **Add user**
   - Email: `admin@topglass.com`
   - Password: `admin123`
   - Скопируйте **UID** пользователя
3. **Realtime Database** → добавьте структуру:
   ```
   admins/
     └── [ваш UID]/
           └── role: "admin"
   ```

### 2. Войдите на сайт

1. Откройте `index.html` в браузере
2. Введите email и пароль
3. Нажмите **Войти**

## 📋 Возможности

### Для администратора:
- ✅ Управление пользователями (просмотр, удаление)
- ✅ Добавление и редактирование статей
- ✅ Удаление статей
- ✅ Сброс просмотров
- ✅ Загрузка изображений и видео

### Для обычных пользователей:
- ✅ Просмотр всех статей
- ✅ Поиск по статьям (с умным стеммингом)
- ✅ Предложение новых тем

## 🔐 Система авторизации

- При открытии сайта показывается форма входа/регистрации
- Только авторизованные пользователи видят контент
- Два типа пользователей: **Администратор** и **Пользователь**
